# ProyectoPOO

Proyecto desarrollado en C++ utilizando Programación Orientada a Objetos (POO) para modelar un sistema de exploración ecológica compuesto por zonas, exploradores y elementos interactivos.

## Descripción

El sistema permite representar diferentes zonas de un entorno natural y la interacción de exploradores con distintos elementos del ecosistema, como:

- Animales heridos
- Reservas naturales
- Contaminantes
- Viveros

El proyecto fue diseñado aplicando principios fundamentales de POO con una arquitectura modular basada en múltiples clases y archivos separados.

---

## Características

- Implementación de herencia y polimorfismo.
- Sistema modular usando archivos `.h` y `.cpp`.
- Interacción dinámica entre objetos.
- Manejo de zonas y elementos interactivos.
- Diseño extensible para agregar nuevas entidades.
